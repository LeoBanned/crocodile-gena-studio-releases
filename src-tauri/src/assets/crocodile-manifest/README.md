# Crocodile Manifest for Millennium

Плагин добавляет кнопку **«Получить манифест»** на страницы игр в магазине настольного клиента Steam.

После нажатия плагин:

1. определяет AppID открытой игры;
2. получает ZIP-пакет через выбранный сервис Ryuu или HubCap;
3. проверяет встроенные OpenSteamTool.dll, dwmapi.dll и xinput1_4.dll в корне Steam, обновляет их с резервной копией;
4. помещает Lua-файлы в `Steam/config/lua`;
5. помещает manifest-файлы в `Steam/depotcache`;
6. предлагает перезапустить Steam.

Дополнительно плагин показывает состояние игры и наличие обновления прямо на
странице магазина, сохраняет историю операций, позволяет удалить файлы выбранной
игры и поддерживает режимы карточки `Full`, `Button` и `Crocodile`. Для HubCap
рядом с кнопкой отображаются использованный дневной лимит и оставшееся число
скачиваний.

## Требования

- Windows 10 или новее;
- установленный [Millennium](https://steambrew.app/);
- доступ к `generator.ryuu.lol`;
- PowerShell, входящий в Windows.

## Сборка

```powershell
npm install
npm run build
```

## Установка

Скопируйте всю папку `crocodile-manifest` в:

```text
<Steam>\millennium\plugins\crocodile-manifest
```

Версия плагина: **0.5.0**. Не исключайте `backend/loader` и
`backend/install-loader.ps1` из комплекта. В программе установка/обновление
плагина сразу настраивает тот же загрузчик, что использует CrocLua.
Если старые DLL заняты Steam, полностью закройте Steam и обновите плагин через
программу. Плагин не завершает Steam принудительно и не запускает DLL сам.
Оригиналы обновляемых DLL и конфига сохраняются в `Steam/config/cgs-luatools-backups`.

Затем:

1. полностью перезапустите Steam;
2. откройте настройки Millennium;
3. включите **Crocodile Manifest**;
4. ещё раз перезапустите Steam;
5. откройте страницу любой игры в магазине.

## Примечания

- Первая версия ориентирована на Windows.
- Кнопка появляется только на адресах `store.steampowered.com/app/<AppID>`.
- Строки `setManifestid` в Lua комментируются так же, как в модуле CrocLua, чтобы Steam мог обновлять данные.
- Если Steam изменит разметку магазина, селектор места для кнопки может потребовать обновления.
