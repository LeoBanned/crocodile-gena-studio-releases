# Участие в проекте

Спасибо за интерес к Crocodile Gena Studio.

## Что можно предложить

- воспроизводимый отчёт об ошибке;
- идею по интерфейсу или новой функции;
- исправление документации;
- улучшение русского текста или предложение будущей локализации.

Исходный код приложения в этом репозитории не опубликован, поэтому Pull Request с изменениями программы сейчас не принимаются. Pull Request для документации можно предложить после предварительного обсуждения в Issue.

## Правила хорошего отчёта

- одна проблема — один Issue;
- используйте понятный заголовок;
- указывайте версию программы и Windows;
- приводите минимальные шаги воспроизведения;
- не публикуйте API-ключи, токены и персональные данные;
- не прикладывайте чужие защищённые материалы.

Отправляя текст или графику, вы подтверждаете, что вправе это сделать и разрешаете проекту использовать материал в документации Crocodile Gena Studio.
