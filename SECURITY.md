# Безопасность

## Поддерживаемая версия

Исправления безопасности выпускаются только для последней опубликованной версии Crocodile Gena Studio.

## Как сообщить о проблеме

Не публикуйте уязвимость, API-ключ, токен или персональные данные в открытом Issue.

Для непубличного сообщения используйте **Private vulnerability reporting** в разделе Security репозитория. Если эта функция временно недоступна, свяжитесь с автором лично: [@crocodilehub2](https://t.me/crocodilehub2).

В сообщении укажите:

- версию Crocodile Gena Studio и Windows;
- затронутый модуль;
- шаги воспроизведения;
- возможное влияние;
- безопасный пример или скриншот без секретных данных.

Не проводите проверку на чужих устройствах, аккаунтах или данных без явного разрешения владельца.
