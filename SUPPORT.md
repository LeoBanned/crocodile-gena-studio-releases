# Поддержка Crocodile Gena Studio

## Перед обращением

1. Убедитесь, что установлена последняя версия из [официальных Releases](https://github.com/LeoBanned/crocodile-gena-studio-releases/releases/latest).
2. Перезапустите приложение и игровой клиент.
3. Проверьте подключение к интернету и доступность выбранного стороннего сервиса.
4. Повторите действие и запишите точный текст ошибки.

## Что приложить к Bug report

- версию Crocodile Gena Studio;
- версию Windows;
- название модуля;
- точные шаги до появления ошибки;
- ожидаемый и фактический результат;
- скриншот, если он помогает понять проблему.

Удалите из материалов API-ключи, токены, имя пользователя Windows и другие личные данные.

## Каналы связи

- Ошибка: [создать Bug report](../../issues/new?template=bug_report.yml)
- Идея: [создать Feature request](../../issues/new?template=feature_request.yml)
- Telegram автора: [@crocodilehub2](https://t.me/crocodilehub2)

Issues предназначены для воспроизводимых ошибок и предложений. Вопросы по аккаунтам сторонних сервисов решаются их собственной поддержкой.
