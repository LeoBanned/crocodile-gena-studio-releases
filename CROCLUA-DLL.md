# Обновление DLL в CrocLua

Окно **«Обновить DLL»** показывает папку Steam, список файлов и результат операции. CrocLua сохраняет ранее выбранное расположение. При стандартном расположении все три DLL находятся в корне Steam. В режиме совместимости только `dwmapi.dll` находится в `Steam/bin`.

Кнопка запрашивает `latest.json` по прямой ссылке на ветку `croclua-dll-feed`. ZIP скачивается только для ревизии, которая новее встроенного и сохранённого комплектов. Проверяются SHA-256 архива и каждой DLL, состав архива и формат файлов. При сбое запроса используется сохранённый комплект или встроенные DLL. Совпадающие файлы пропускаются. При замене прежние файлы сохраняются в `Steam/config/cgs-luatools-backups`.

CrocLua и Crocodile Manifest используют сохранённые DLL при добавлении игр. Этот сценарий работает без обращения к GitHub. Если Steam удерживает DLL, полностью закройте его и повторите обновление из CrocLua.

## Публикация нового комплекта

Положите три DLL в папку `ffedw` на рабочем столе и запустите `tools/Publish-CrocLuaDlls.cmd`. Можно также перетащить другую папку с DLL на этот файл. Скрипт читает текущую ревизию из открытого файла GitHub и сохраняет ZIP и `latest.json` в `build/croclua-dll-upload/revision-N`. Загрузите оба файла в корень ветки `croclua-dll-feed` одним коммитом, заменив её `latest.json`.

При ручной публикации действуйте в ветке `croclua-dll-feed` репозитория `LeoBanned/crocodile-gena-studio-releases`:

1. Увеличьте целое число `revision` в `latest.json`. Номера опубликованных комплектов используются один раз.
2. Создайте `dll-<revision>.zip` с тремя файлами в корне архива: `OpenSteamTool.dll`, `dwmapi.dll` и `xinput1_4.dll`.
3. Запишите SHA-256 ZIP в `sha256` и SHA-256 каждого файла в объект `files`, используя строчные шестнадцатеричные значения.
4. Опубликуйте ZIP и `latest.json` одним коммитом в этой ветке.

При включении нового комплекта в EXE обновите DLL в `src-tauri/src/assets/` и номер в `loader-revision.txt`. Синхронизируйте ресурсы самостоятельной сборки плагина в `src-tauri/src/assets/crocodile-manifest/backend/loader/`, включая `revision.txt`.
