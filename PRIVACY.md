# Конфиденциальность

Дата редакции: 1 августа 2026 года.

Crocodile Gena Studio не требует создания отдельной учётной записи приложения.

## Локальные данные

Приложение может сохранять на компьютере пользователя настройки интерфейса, выбранные пути, выбранный сервис манифестов и введённый API-ключ HubCap. Эти данные нужны для восстановления настроек между запусками.

Пользователь может удалить локальные настройки вместе с данными приложения или сбросить соответствующие значения в интерфейсе.

## Сторонние сервисы

При использовании сетевых функций приложение отправляет необходимые запросы напрямую выбранным сервисам. Например, ключ API передаётся сервису, для которого он был создан. Обработка таких запросов регулируется правилами и политикой конфиденциальности соответствующего сервиса.

Проверка обновлений обращается к GitHub. Получение сведений об играх может обращаться к публичным сервисам Steam и другим выбранным пользователем источникам.

## Диагностика

Приложение не должно автоматически публиковать ваши API-ключи. Перед отправкой скриншота или журнала в поддержку убедитесь, что в нём нет ключей, токенов, адреса электронной почты и личных путей к файлам.

## Изменения

При изменении поведения приложения эта страница может быть обновлена. Актуальная редакция публикуется в официальном репозитории.
