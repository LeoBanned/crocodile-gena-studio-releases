# Установка Crocodile Gena Studio

## Обычная установка

1. Перейдите на страницу [последнего релиза](https://github.com/LeoBanned/crocodile-gena-studio-releases/releases/latest).
2. В блоке **Assets** выберите установщик актуальной версии.
3. Дождитесь окончания загрузки.
4. Закройте Steam и другие игровые клиенты перед операциями с их файлами.
5. Запустите установщик и завершите установку.
6. Откройте Crocodile Gena Studio через ярлык или исполняемый файл приложения.

## Обновление

Приложение проверяет наличие новой версии при запуске. Если обновление не определяется автоматически, скачайте новый установщик из Releases и установите его поверх текущей версии.

Перед крупным обновлением рекомендуется закрыть программу и сохранить резервные копии важных игровых сохранений.

## Windows SmartScreen

Windows может показать предупреждение для нового или редко загружаемого файла. Проверьте, что адрес страницы начинается с официального репозитория `LeoBanned/crocodile-gena-studio-releases`, и только после этого принимайте решение о запуске.

## Если приложение не запускается

- установите все ожидающие обновления Windows;
- перезагрузите компьютер;
- временно переместите установщик в папку с простым путём без специальных символов;
- убедитесь, что защитная программа не поместила файл в карантин;
- повторно скачайте установщик из официального релиза;
- создайте Bug report с версией Windows и точным текстом ошибки.

Никогда не отключайте защиту системы насовсем и не публикуйте в обращении API-ключи.
