# Как опубликовать подготовленную папку

Рекомендуемый адрес: `https://github.com/LeoBanned/crocodile-gena-studio-releases`.

## Вариант через сайт GitHub

1. Откройте существующий репозиторий `crocodile-gena-studio-releases`.
2. Если в ветке уже есть важные файлы, сначала сохраните их копию.
3. Нажмите **Add file → Upload files**.
4. Перетащите содержимое папки `CrocodileGenaStudio-GitHub`, сохраняя структуру каталогов.
5. Укажите сообщение `Add Crocodile Gena Studio product page` и подтвердите изменения.
6. Откройте главную страницу и проверьте README, изображение и ссылки.

GitHub может быть неудобен для загрузки вложенных папок через браузер. В таком случае используйте GitHub Desktop или Git.

## Вариант через Git

Сначала клонируйте существующий репозиторий, затем скопируйте в него содержимое подготовленной папки. После проверки выполните:

```powershell
git add .
git status
git commit -m "Add Crocodile Gena Studio product page"
git push origin main
```

Команда `git status` обязательна: перед отправкой убедитесь, что в списке нет установщиков, DLL, API-ключей, локальных логов и временных файлов.

## Публикация новой версии

1. Соберите и протестируйте установщик отдельно от публичной папки.
2. Откройте **Releases → Draft a new release**.
3. Создайте тег вида `v4.0.3` или следующей актуальной версии.
4. Добавьте установщик в **Assets**.
5. Добавьте SHA-256 файла и список изменений.
6. Опубликуйте Release и проверьте обновление из предыдущей версии программы.

Установщик не нужно добавлять в ветку `main`: `.gitignore` специально исключает такие файлы.
