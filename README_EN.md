## About

Crocodile Gena Studio brings several game-related workflows into one desktop application. It replaces scattered folders, scripts, and consoles with a consistent interface, clear operation statuses, and automatic update checks.

### Highlights

- **Online Fix** — install, verify, and restore supported game components through a guided workflow.
- **Save Manager** — locate save data and create backups of game progress.
- **DLC Unlocker** — manage compatible game components from one interface.
- **CrocLua** — Steam library workflows with user-provided manifest-service API keys.
- **Status and history** — see the result of each operation without watching a console window.
- **Automatic updates** — check for a new version whenever the application starts.

## Requirements

- 64-bit Windows 10 or Windows 11;
- an internet connection for component lookup, selected third-party services, and update checks;
- Steam or another supported game client only when a selected feature requires it;
- administrator privileges for operations that modify installed application files.

The current application interface is in Russian. English localization is not claimed as available yet.

## API keys and privacy

Some features require a personal API key for a third-party service. The key is entered by the user, stored locally on that computer, and used for requests to the selected service. Never include API keys in issues, screenshots, or logs.

Read the [privacy notice](PRIVACY.md) for details.
